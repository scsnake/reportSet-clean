Usage:
- execute "Hotstring Helper.exe": load .ahk files in the same folder
- execute "Hotstring Helper.exe [AHKPATH1 [AHKPATH2] ... ]": load .ahk files from arguments

Hotkeys:
- edit "Hotstring Helper.ini" for settings
- preSearch: type preSearch character (default: ";") and keyword (at least 3 alphabets) to initiate search, can dynamically update search result
- postSearch: type keyword then postSearch character (default: "'") to initiate search
- keywordSearch: select several words (can have spaces), type keywordSearch hotkey (default: Alt + F) to initate search for selected words
- for preSearch and keywordSearch, can include "?" or "*" in the keyword

Search Result:
- PageUp, PageDown, mouse wheel up/down to navigate pages
- Esc to cancel
- Space to select first result, number (1, 2, 3 to 0) to select specific result
